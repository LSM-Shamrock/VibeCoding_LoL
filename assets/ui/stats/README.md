# 능력치 아이콘

이 폴더에 아래 이름의 PNG 파일을 넣으면 인게임 능력치 패널(HUD 왼쪽)에 아이콘으로 표시됩니다.
파일이 없으면 색 사각형 + 글자 임시 아이콘이 나옵니다. 크기는 자유(20x20 으로 줄여서 그림), 투명 배경 권장.

| 파일 | 능력치 |
| --- | --- |
| `ad.png` | 공격력 |
| `ap.png` | 주문력 |
| `armor.png` | 방어력 |
| `mr.png` | 마법 저항력 |
| `attack_speed.png` | 공격 속도 |
| `move_speed.png` | 이동 속도 |
| `ability_haste.png` | 스킬 가속 |
| `crit.png` | 치명타 확률 |
